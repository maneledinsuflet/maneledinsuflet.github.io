Despre Manele din suflet

Manele din suflet este un proiect muzical născut din pasiunea pentru muzică și pentru poveștile adevărate ale oamenilor.

Fiecare melodie poartă o emoție, un mesaj și o parte din viață. Muzica nu este doar sunet. Muzica este amintire, iubire, dor și suflet.
